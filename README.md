# 🛒 Blinkit Sales & Outlet Performance Dashboard

An interactive **Power BI dashboard** built to analyze Blinkit's sales performance, outlet characteristics, product categories, customer ratings, and item visibility.

The dashboard transforms raw retail data into meaningful business insights through interactive KPIs, charts, filters, and detailed outlet-level analysis.

## 📌 Project Overview

This project focuses on analyzing Blinkit's retail sales data to understand how different **product types, outlet characteristics, location tiers, outlet sizes, and fat content categories** contribute to overall business performance.

The dashboard provides an interactive view of:

- 💰 Total Sales
- 📦 Number of Items Sold
- ⭐ Average Customer Rating
- 💵 Average Sales per Item
- 🏪 Outlet Performance
- 📍 Outlet Location/Tier Analysis
- 📏 Outlet Size Analysis
- 🥫 Item Type Performance
- 🥗 Fat Content Distribution
- 👁️ Item Visibility
- 📅 Outlet Establishment Trends

Users can interact with the dashboard using filters for **Outlet Location Type, Item Type, and Outlet Size**.

---

## 🎯 Business Objective

The primary objective of this project is to help Blinkit understand its retail performance and identify factors influencing sales.

### Key Business Questions

- What is the overall sales performance?
- Which product categories generate the highest sales?
- How does outlet size affect sales?
- Which outlet location tier performs the best?
- How does fat content influence product sales?
- Which outlet types generate the most revenue?
- How does outlet establishment year relate to sales?
- What is the average customer rating?
- Which outlets have the highest number of items?
- How visible are products across different outlet types?

## 🛠️ Tools & Technologies

### Power BI
Used to build the interactive dashboard, visualizations, KPIs, filters, and analytical views.

### Power Query
Used for:

- Data cleaning
- Data transformation
- Handling missing values
- Preparing data for analysis

### DAX
Used to create calculated measures and KPIs such as:

- Total Sales
- Average Sales
- Average Rating
- Number of Items

### Microsoft Excel / CSV
Used as the source/data preparation environment for the retail dataset.
